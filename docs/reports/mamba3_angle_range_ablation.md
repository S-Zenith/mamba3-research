# 旋转角度范围消融：从 ±π 到完全不旋转

## 实验设计

固定 bigstate-long 配置（d_model=256, n_layer=4, headdim=64, d_state=4, 5000步），系统改变 RoPE 旋转角度范围，观察对 FP32 精度和 INT8 量化鲁棒性的影响。

| angle_mode | 角度范围 | cos 范围 | 旋转计算 |
|---|---|---|---|
| tanh | ±π | [-1, 1]（有符号翻转） | cos/sin |
| tanh_half | ±π/2 | [0, 1]（非负） | cos/sin |
| tanh_quarter | ±π/4 | [0.707, 1]（接近1） | cos/sin |
| none | 0（不旋转） | 1（恒等） | 无 |
| rsqrt | ±π/2 (arctan) | [0, 1] | rsqrt |

## 完整 5000 步结果

| angle_mode | 范围 | gate | FP32 val_loss | W8A8 ratio | pct999 ratio |
|---|---|---|---|---|---|
| tanh | ±π | silu | 8.37 | 5775x | 1.68x |
| tanh | ±π | relu | 9.45 | 28.9x | 1.68x |
| **tanh_half** | **±π/2** | **silu** | **6.62** | 1.47x | 1.25x |
| **tanh_half** | **±π/2** | **relu** | 6.78 | 1.28x | 1.11x |
| tanh_quarter | ±π/4 | silu | 6.80 | 4.62x | 1.38x |
| **tanh_quarter** | **±π/4** | **relu** | 7.05 | 1.43x | **1.04x** |
| none | 0 | silu | 7.01 | 1.28x | **0.99x** |
| none | 0 | relu | 6.76 | 1.31x | 1.21x |
| rsqrt | ±π/2 | silu | 8.50 | 381100x | 6.49x |
| rsqrt | ±π/2 | relu | 6.80 | 2.01x | 1.29x |

## 关键发现

### 1. 角度范围与精度的关系是非单调的

**FP32 val_loss 随角度范围的变化**（silu）：

```
±π → 8.37（最差）
±π/2 → 6.62（最好）
±π/4 → 6.80
0 → 7.01
```

**不是越小越好**。±π/2 是 FP32 精度的最优点，±π/4 和完全不旋转都比 ±π/2 差。

原因：旋转为 Q/K 提供了**位置编码**——不同位置的 Q 和 K 以不同角度旋转，使 attention scores `QK^T` 能区分位置。角度越大，位置区分能力越强，但 ±π 的符号翻转破坏了稳定性。±π/2 是区分能力和稳定性的最佳平衡点。

完全不旋转（0）时，Q 和 K 只有内容信息没有位置信息，模型需要完全依赖 decay（exp(ΣA·dt)）来建模时序关系，表达力下降。

### 2. 量化鲁棒性随角度缩小而改善，但不旋转反而变差

**pct999 ratio 随角度范围的变化**（relu）：

```
±π → 1.68x
±π/2 → 1.11x
±π/4 → 1.04x（最好）
0 → 1.21x（反而变差）
```

±π/4 是量化鲁棒性的最优点（relu, pct999 ratio=1.04x，几乎通过 10%）。但完全不旋转反而退化到 1.21x。

原因：旋转引入的 cos/sin 值在 ±π/4 时非常接近 1（cos(π/4)≈0.707），量化后几乎无损。完全不旋转时 cos=1 是常数，但 attention scores `QK^T` 的分布不同（无位置调制），激活值的离群模式改变，量化敏感性反而上升。

### 3. 不旋转 + SiLU 的意外发现：量化比 FP32 更好

**none+silu 的 pct999 ratio = 0.99x**（小于 1.0！）。这意味着 INT8 量化后的模型比 FP32 模型精度更好。

这是 lm_head 正则化效应的延伸：INT8 量化裁剪了极端激活值，相当于全链路正则化。当模型结构简单（无旋转）时，这种正则化效果更显著。

### 4. 角度范围 vs 旋转函数：范围更重要

| 对比 | 角度范围 | 旋转函数 | FP32 | pct999 ratio |
|---|---|---|---|---|
| tanh_half+relu | ±π/2 | cos/sin | 6.78 | 1.11x |
| rsqrt+relu | ±π/2 | rsqrt | 6.80 | 1.29x |

相同范围下 cos/sin 优于 rsqrt（1.11x vs 1.29x）。rsqrt 的 arctan 虽然范围也是 ±π/2，但 arctan 的非线性梯度不如 tanh+cos/sin 平滑。

### 5. 各配置的最优组合

| 目标 | 最优配置 | 理由 |
|---|---|---|
| FP32 最好 | tanh_half+silu (±π/2) | 6.62，位置编码+稳定性最佳平衡 |
| 量化最好 | tanh_quarter+relu (±π/4) | pct999=1.04x，cos接近1量化无损 |
| 硬件最简 | none+relu (不旋转) | 无需LUT，FP32=6.76，pct999=1.21x |
| 综合最优 | tanh_half+relu (±π/2) | FP32=6.78，pct999=1.11x |

## 为什么角度范围影响精度和量化

### 对 FP32 的影响

旋转角度作用于 selective scan 的 Q/K attention 计算：
```
qk = (q · R(θ)) · (k · R(θ))^T = q · R(θ) · R(θ)^T · k^T = q · k^T  （如果 R 正交）
```

但 RoPE 只作用于部分维度（d_state//2 对），所以：
```
qk = q_unrotated · k_unrotated^T + q_rotated · R(2θ) · k_rotated^T
```

其中 `R(2θ)` 是 2×2 旋转矩阵。θ 决定了 Q 和 K 在旋转维度上的**相对角度差**：
- θ=0：无位置区分（QK 点积与位置无关）
- θ=±π/2：最大有效区分（cos 非负，sin 最大）
- θ=±π：区分但不稳定（cos 翻转，sin=0 梯度消失）

### 对量化的影响

量化误差通过旋转矩阵传播。旋转矩阵 `[[cos,-sin],[sin,cos]]` 的条件数：
- θ=0：条件数=1（恒等矩阵，误差不放大）
- θ=±π/4：条件数=1（正交矩阵，误差不放大）
- θ=±π/2：条件数=1（正交矩阵，但 cos 在 0 附近量化后不确定）
- θ=±π：条件数=1，但 cos 符号翻转导致量化后矩阵可能不是旋转矩阵

关键不是条件数，而是 **cos 的符号**：当 cos 为负时，量化后的 cos 可能从负变正或从正变负，完全改变旋转方向。±π/2 保证 cos≥0，消除这个问题。

## 结论

1. **±π/2 是 FP32 精度的最优点**——位置区分能力和稳定性的最佳平衡
2. **±π/4 是量化鲁棒性的最优点**（relu）——cos 接近 1，量化几乎无损
3. **完全不旋转也可用**——FP32 仅差 2-3%，但失去了位置编码能力
4. **±π 是一致最差的**——cos 符号翻转是量化的致命问题
5. **角度范围比旋转函数更重要**——相同范围下 cos/sin 优于 rsqrt

### ASIC 设计启示

| 优先级 | 方案 | 角度范围 | pct999 ratio | 硬件 |
|---|---|---|---|---|
| 精度优先 | tanh_half+relu | ±π/2 | 1.11x | 3 LUT (tanh+cos+sin) |
| 量化优先 | tanh_quarter+relu | ±π/4 | 1.04x | 3 LUT |
| 面积优先 | none+relu | 0 | 1.21x | 0 LUT（无旋转） |
| 折中 | rsqrt+relu | ±π/2 | 1.29x | 1 rsqrt 单元 |

如果 ASIC 面积允许 3 个小 LUT，**tanh_quarter+relu（±π/4）** 是最佳选择：pct999 ratio=1.04x，几乎通过 10% 标准，且 cos/sin 在 ±π/4 范围内可以用极简 LUT（cos 值仅 [0.707, 1.0]，只需 64 个 entry）。
